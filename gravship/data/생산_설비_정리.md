# 생산·제조·채굴 설비 정리

모드 목록 `260924-12 경량 OP 번역` 기준, 패치 반영. 작업대 61개, 제작품 1392종. 전체 값은 `benches.csv`(작업대), `products.csv`(제작품별 작업대·속도), `item_sources.csv`(모드 아이템 획득 경로).

**판정 기준**
- **대체 가능**: 이 작업대의 제작품이 **전부** 다른 작업대에서도 만들어짐 → 안 지어도 됨. 제작품 비교는 결과물 기준(레시피 재료가 다를 수 있음).
- **필수**: 여기서만 만드는 제작품이 있음. **선택**: 제작품이 여러 작업대에 나뉘어 있어 다른 필수 작업대 조합으로 모두 커버됨.
- 속도 = 작업대 기본 작업 속도 + 연결 설비 최대 보너스(`연결설비_정리.md` 기준). 정착민 능력·조명·방 청결 등은 제외.
- **공허 추출기(Void Extractor) 모드는 요청대로 판단에서 제외**(추출기 2종 + 석재 절단기의 돌덩이 변환 레시피 5종). 그것으로만 얻는 아이템은 6장에 따로 표시.
- 모드가 C# 코드로 레시피를 만들거나 자체 창으로 생산하는 설비는 정의 파일에 안 나와 빠질 수 있음(예: 밀리라 가상 생산 장치는 레시피 자동화).
