# 중력선 설계용 시설 정리

모드 목록 `260924-10 경량 OP 번역` 기준. 게임 정의 파일(XML)에서 직접 뽑은 값이며, 전체 목록은 `facilities.csv`(건물 823개), 바닥은 `floors.csv`에 있습니다.

**읽는 법**

- 크기는 `가로x세로`(회전 전). 전력 `-` 는 소비, `+` 는 발전.
- **실제 적용값**: Bigger Gravships·GravTech 는 게임 설정으로 정의값을 덮어씁니다. 표의 `[Bigger Gravships]`, `[GravTech]` 값이 실제 게임 값입니다.
- 다른 모드의 패치(XML Patch)는 반영하지 않았습니다. 밀리라처럼 자체 코드로 전력을 쓰는 건물은 전력 칸이 비어 있을 수 있습니다.
- `작업칸`은 사람이 서서 일하는 칸(건물 기준 좌표). 벽·다른 건물로 막으면 안 됩니다.

## 1. 2만 칸 설계 핵심 수치

### 하부구조 지지량 (몇 칸까지 지을 수 있나)

| 출처 | 1개당 지지 | 최대 개수 | 비고 |
|---|---|---|---|
| 중력구동기(엔진) | 5,000칸 | 1 | Bigger Gravships 설정. 바닐라는 500 |
| 중력장 확장기 | 5,000칸 | 100 | Bigger Gravships 설정. 엔진에서 100칸 이내, 반경 100 |
| GravTech 중력장 파일런 | 2,000칸 | 20 | GravTech 설정. 반경 100 |
| GravTech 특이점 반응로 | 5,000칸 | 20 | GravTech 설정. 발전 500,000 W, 반경 100 |

→ **엔진 1 + 중력장 확장기 3개 = 20,000칸.** 여유를 두려면 확장기 4개(25,000칸) 또는 특이점 반응로 1개 추가(발전 겸용).

- 하부구조 반경: 엔진 100(Bigger Gravships) / 150(GravTech) — 두 모드가 같은 값을 설정하므로 실제 값은 게임에서 엔진 선택 시 확인.
- 2만 칸은 대략 **141×141** 정사각형. 엔진 반경 100 안에 충분히 들어가지만, 확장기·파일런의 `엔진 거리` 제한 안에 배치해야 합니다.
