# 방어·전투 시설 성능

모드 목록 `260924-10` 기준, 게임 정의(XML)에서 계산. 전체 값은 `combat.csv`.

- **추정 DPS** = 연사 발수 × 1발 피해 ÷ (조준 + 재사용 + 연사 간격). 명중률·방어구·폭발 범위 피해는 빼고 계산한 단순 비교용.
- **관통력**: 방어구 관통. 방어구 수치보다 높을수록 피해가 덜 깎임.
- **명중(근/중/원)**: 무기 기본 명중률(3·12·25칸 기준). 포탑은 여기에 포탑 사격 정확도가 곱해짐.
- 셀레테크·밀리라 일부 포탑은 전용 코드(업그레이드·특수 탄)가 있어 실제 성능이 표보다 높을 수 있음.
- 공중 요격·보호막 칸의 `interceptAirProjectiles=true` 는 박격포·폭격 같은 **위에서 떨어지는 공격**을 막는다는 뜻.
- 피해·DPS 칸이 빈 포탑(셀레테크 입자 랜스·화염방사 벙커·프리즘 탑 등)은 피해를 전용 코드로 처리해서 정의에 수치가 없음.
- 전투기는 호출·출격형이라 DPS 는 참고용(출격 1회 동안의 사격 성능).
- 포탑의 `파괴 시 폭발 반경`은 포탑이 부서질 때 주변에 터지는 범위 — 중력선 안쪽에 둘 때 주의.
